# SmallClick — sitio web

Sitio bilingüe (EN/ES) con precios en USD/MXN, cupón de 8 %, popup de cotización y aviso de privacidad.

- `index.html` — la página principal (no hace falta editarla).
- `privacy.html` — aviso de privacidad. Llena tus datos legales en el bloque `LEGAL`, al final del archivo.
- `config.js` — **lo único que editas**: precios, fecha límite, enlaces de Stripe, WhatsApp, portafolio.
- `portfolio/` — capturas de tus trabajos.

Publicado con GitHub Pages: Settings → Pages → Branch `main` / `(root)`.
