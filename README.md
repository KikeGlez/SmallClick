# SmallClick — sitio web

- `index.html` — página principal (no hace falta editarla).
- `privacy.html` — aviso de privacidad (llena el bloque LEGAL al final).
- `config.js` — lo único que editas: precios, fecha límite, Stripe, WhatsApp, portafolio.
- `portfolio/` — capturas de tus trabajos (computadora + celular).
